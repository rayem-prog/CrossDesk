# CrossDesk 0.6.2 — 键鼠与双向复制粘贴

Windows 与 Apple Silicon Mac 共享键鼠，双向复制纯文字、图片、文件和原样文件夹。基于 [Deskbridge](https://github.com/paulhe666/deskbridge)，保留 GPL v3。

## 开始使用

**第一次：** Windows 安装并打开 CrossDesk，Mac 将 `CrossDesk.app` 拖入“应用程序”后打开。在 Mac 上选择发现的 Windows，输入 Windows 窗口中的六位配对码，点击“配对并连接”。

**以后：** 两台电脑打开 CrossDesk，自动连接；看到“可以开始复制粘贴”，就能直接复制文字、截图、图片、文件或文件夹，在另一台粘贴。默认开启文字、图片与文件同步。不需要终端、IP 地址或搬运密钥文件。

- 推荐两端使用 0.6.2 GUI 应用，并连接同一局域网。Windows 为键鼠服务端，Mac 为客户端；文字/文件/图片传输双向。
- Mac 首次使用需要允许“本地网络”和“系统设置 → 隐私与安全性 → 辅助功能”中的 CrossDesk。授权后点击“连接设备”，必要时重新打开应用。
- Windows 首次防火墙提示时允许当前使用的专用网络。访客 Wi-Fi / AP 隔离可能阻止设备互相发现。
- 配对码 120 秒有效；失效后 Windows 点击“重新生成配对码”。错误码不会建立信任。首次配对成功后不用再次输入。
- 点击“断开连接”后，本次运行保持断开；点击“连接设备”恢复。关闭应用会停止服务和发现，不在后台常驻。
- 设置按钮中可分别关闭自动连接、文字、图片或文件同步，查看日志，或在两端都忘记设备后重新配对。修改同步选项前先断开。

这些构建尚无可信发布签名 / Apple 公证。Mac 若提示未验证开发者，请按系统“隐私与安全性”的允许打开流程处理；不要关闭系统安全防护。Windows 安装程序可能显示 SmartScreen 提示。开发者本地构建与 CI 安装包不等于正式 GitHub Release。

## 发现失败与旧版迁移

先检查两端已打开、网络相同、本地网络/防火墙权限已允许，然后刷新。仍失败时可在“高级设置 → 手动连接与旧版迁移”中指定 Windows IP 和旧版 `crossdesk.key`。已有其他配对时需先忘记设备；新 GUI 配对材料自动存入每用户应用数据目录，不放在安装目录。

局域网发现使用 mDNS UDP 5353，临时配对使用 TCP 24921，数据使用原有 TCP 24920 / 协议 v7。公告只提供设备地址，不构成信任；六位码通过 SPAKE2、HKDF 和 Noise 确认后交付随机长期密钥。采用的 RustCrypto SPAKE2 库说明其实现未经独立安全审计，本项目也不声称已审计。只支持一组 Windows/Mac 配对。

升级至 0.6.2 后沿用已有配对、密钥和偏好，无需重新配对；旧偏好缺少文字选项时默认开启。与 0.5.0 连接时，图片、文件及文件夹继续可用，首页提示“对端未开启或不支持文字同步”。协议低于 v7 才需要升级后连接。命令行入口继续保留，正常 GUI 使用无需以下命令：

```sh
crossdesk keygen --out crossdesk.key
crossdesk server --edge both --key-file crossdesk.key
crossdesk client --server WINDOWS_IP:24920 --key-file crossdesk.key
```

## 后台运行、登录启动与诊断（0.6.2）

- 首页点“后台运行”隐藏窗口，键鼠和复制粘贴继续工作；从 Mac 菜单栏或 Windows 托盘重新打开。
- **关闭窗口仍会彻底退出程序**。托盘菜单也有“退出”；暂停会断开连接并释放输入，恢复使用已有配对。
- 高级设置或托盘里的“登录时启动”默认关闭，开启后登录时以后台模式运行，沿用原自动连接设置。未配对或需要授权时显示窗口。开关以系统实际状态为准，失败会提示，不会假装已开启。
- 手动再次打开应用会恢复已有窗口；重复的后台启动不抢焦点。不需要管理员服务；应用必须保存在固定位置（Mac 建议先放入“应用程序”），移动后请重新关闭并开启登录启动。
- 高级设置中的“输入诊断”在连接期间采样 60 秒，无需重连，支持提前停止和导出 JSON。显示本机发送排队、网络写入、接收排队、系统注入和发送节奏迟到量；没有样本显示“暂无数据”。分位数为微秒桶上界，不代表屏幕端到端延迟。
- 诊断默认关闭，由后端计时，窗口隐藏不影响到期；断线清空当前会话数据。报告只包含版本、平台和计数/耗时/队列统计，不保存剪贴板正文、键值、坐标、对端地址或密钥。
- 隐藏或最小化后暂停网页轮询，托盘与连接由 Rust 后端维护；恢复窗口立即刷新。后台功能保持协议 v7，可与 0.6.1 沿用原有配对。

## 双向纯文字同步

连接成功后重新复制文字，等待首页显示“文字已同步”，在另一端编辑器或支持文字的应用中直接粘贴。支持中文、emoji、多行代码、缩进、首尾空格及空白行；仅同步纯文本，不保留 HTML / RTF 样式。

- 单次最多 **1 MiB，按规范化后的 UTF-8 字节数计算**。内部统一 LF，Windows 发布为 CRLF。
- 空字符串不传播清空；含 NUL、无效编码或超限整批跳过并显示原因，不截断、不清空目标、不影响键鼠连接。
- 只同步连接之后新复制的内容；启动前及断线期间的内容不会补发。对方有更新的本地复制时会跳过旧任务；重新复制相同文字也可重试。远端发布不会回传。
- 文字与图片、文件共用发布队列和剪贴板版本保护。新复制取消旧发送；每方向最多一个接收批次，30 秒无进展或断线丢弃未完成内容，不保存文字历史或磁盘缓存，日志不记录正文。
- 文字独立开关默认开启，任一端关闭，本次连接双向停止文字同步。修改前先断开；重新连接后生效。对端 0.5.0 或关闭选项时会提示不可用。
- CLI 使用 `--text-clipboard on|off`；例如 `crossdesk client --server WINDOWS_IP:24920 --text-clipboard on --image-clipboard off --file-clipboard off` 仅同步文字并保留键鼠控制。不要用旧实验变量 `CROSSDESK_ENABLE_CLIPBOARD` 开启文字同步。

## 文件和原样文件夹双向互传

连接后**重新复制**要传的文件或文件夹，等待首页传输状态显示“可以粘贴”。整理、传输、等待发布、跳过和失败均有独立提示；传输失败不会被误报成连接断开。

| 复制位置与操作 | 另一端如何粘贴 |
|---|---|
| Windows 资源管理器选中 PDF、DOCX、XLSX、ZIP 等，Ctrl+C | Mac Finder 打开目标文件夹，Command+V |
| Mac Finder 选中普通文件，Command+C | Windows 资源管理器打开目标文件夹，Ctrl+V |
| 选中 PNG/JPG、PDF 和文件夹混合复制 | 另一端粘贴整组文件及完整目录 |
| Finder / 资源管理器选中文件夹复制 | 另一端直接粘贴完整多级目录，无需打包或解压 |

- 支持任意扩展名的普通文件、多级目录、空目录、普通隐藏文件、零字节文件、中文名和混选，保留名称、目录结构与内容。跨设备剪切按复制处理，不删除源文件；接收不自动打开或执行文件。
- 单文件最多 **512 MiB**，每批最多 **2 GiB / 64 个顶层项目**，展开后最多 **10,000 个文件及目录 / 32 层**，两端都执行限制。
- 符号链接、Windows 重解析点、尚未落地的云文件、不可读条目及不符合跨平台规则的名称会导致整批失败，并显示原因。请先下载云内容；本版不迁移权限、扩展属性和链接关系，也不提供断点续传。
- 文件名需可同时用于 Windows 和 Mac：不能含控制字符、路径分隔符、Windows 保留名称或尾部点/空格；单名不超过 255 UTF-8 字节。组内同名和文件系统等价名称会添加序号，不静默覆盖。
- 目录清单按 v7 分帧（每帧最多 64 KiB，清单最多 4 MiB）；内容分块读取、加密传输、分块落盘；每个文件验证长度与 SHA-256，整组完成后才更新剪贴板。按需打开文件，无需将整个文件加载到内存。发送前后复核源文件及目录元数据，发现变化就取消，请在复制期间保持源内容不变；不承诺文件系统快照。
- `transmitted ... waiting for destination publication` 表示已传完，**不等于已更新目标剪贴板**。目标端有更新的本地复制时会跳过发布，源端收到 `skipped ... copy again to retry`。重新复制相同文件也会建立新任务。
- 在源端复制新内容会取消尚未完成的旧文件发送；断线清理本次未发布的暂存文件。重连后重新复制，从头发送，不自动补发断线期间的内容。
- 文件暂存于系统临时目录 `crossdesk-file-clipboard` 的独立批次目录。新批次不会删除旧批次；当前剪贴板引用的缓存受到保护。会话启动时清理超过 24 小时且未被当前剪贴板引用的缓存。
- 文件缓存预算为 4 GiB；达到预算会拒绝新批次并给出原因。已经粘贴到目标文件夹的内容由文件管理器保存；清理缓存前应完成粘贴并清除剪贴板里的旧文件引用，避免在文件管理器仍复制时清理。

任一端手动命令加 `--file-clipboard off`，双方停止文件和文件夹同步；使用 `--file-clipboard on` 或省略该选项恢复。文字使用独立开关，不要用旧实验环境变量 `CROSSDESK_ENABLE_CLIPBOARD` 开启文件互传。

## 图片双向互传

| 复制内容 | 另一端如何粘贴 |
|---|---|
| Windows 截图工具/浏览器的“复制图片” | Mac 聊天、文档、图片应用，Command+V |
| Mac Control+Command+Shift+4 截图到剪贴板，或“复制图片” | Windows 支持图片的应用，Ctrl+V |
| 单张 PNG/JPG/JPEG 文件 | 另一端文件夹，或支持图片剪贴板的应用 |

截图必须复制到剪贴板；只保存到磁盘不触发同步。位图以 PNG 传输，保留透明度；单图表示限制为 32 MiB、32 Mi 像素，宽高不超过 16384。单张图片文件超过图片表示限制时仍可作为普通文件粘贴到文件夹。

图片可用 `--image-clipboard off` 单独关闭。关闭普通文件同步后，图片模式仍可处理符合图片限制的 PNG/JPG 文件（最多 32 张、128 MiB）；文字同步由独立开关控制；三项均关闭才停止本次剪贴板同步。目标聊天/文档应用是否接受图片，仍需对相应应用验证。

## 键鼠与退出

| 操作 | 结果 |
|---|---|
| Windows 左外边界向外划 | 进入 Mac 主屏右侧 |
| Windows 右外边界向外划 | 进入 Mac 主屏左侧 |
| Mac 主屏左/右边界向外划 | 回到 Windows 对应另一侧 |
| Windows Ctrl+Alt+Esc 或 Scroll Lock | 紧急返回 Windows |
| 窗口中的“断开连接” / 关闭应用 | 停止连接 / 完全退出 |

键盘跟随鼠标，Windows Ctrl 对应 Mac Command，Alt 对应 Option。支持点击、滚轮、Mac 内拖动；按住键或按钮时保留控制权，松开后再跨屏。Mac 以主显示器为控制范围，Windows 内部显示器接缝不切换。

复用 Noise NNpsk0 / X25519 / ChaCha20-Poly1305 / SHA-256 加密配对连接；文件块为 16 KiB，确认后再发下一块，键鼠、心跳及控制帧优先。数据传输继续使用 TCP 24920。文件复制与鼠标当前在哪台电脑无关。

## 0.6.1 鼠标发送与积压处理

Windows 在空闲后的首个移动立即发送，连续移动默认按 2 ms 间隔发送。发送线程使用可被新事件唤醒的 Windows 高精度等待计时器；系统不支持高精度标志时回退普通等待计时器。钩子不等待网络或计时器，发送线程不忙等。

两端输入队列最多保存 256 个记录，只合并相邻且每个坐标轴均不反向的鼠标相对移动，并检查坐标相加是否溢出。反向移动、溢出、按键、按钮、滚轮和进入/离开都是合并边界；保留顺序与逐步边缘裁剪的终点语义。Mac 仅压缩已积压移动，不为等待合并额外延迟输入，继续使用 CGEvent 注入。队列无法合并且达到容量时终止本会话并释放按住的输入；停止会清空队列并唤醒消费者，断线动作不会补放。

默认关闭耗时统计。需要诊断时，在启动进程前设置 `CROSSDESK_INPUT_METRICS=1`，通过进程日志查看发送排队、网络写入、接收排队、系统注入与发送节奏迟到量。统计使用固定内存直方图，每 5 秒至多输出一次聚合窗口，包括 count、p50/p95/p99、最大值、合并样本数与最大队列深度。分位数表示微秒桶上界，溢出桶使用实际最大值；这些阶段耗时不代表屏幕端到端延迟。日志不记录坐标、键值、文字正文或密钥。

本版保持协议 v7、现有配对与剪贴板兼容，文件仍走原有连接；没有新增延迟探测或 RTT 消息。自动回归只能验证实现行为，实际流畅度改善需用户在两台设备上体验，不预先保证改善数值。

## 验证与构建

Node.js 24、Rust stable，分别在原生 Windows / Apple Silicon Mac 上构建；Windows 需要 MSVC 构建工具，GUI 使用 WebView2。

```sh
npm --prefix web ci
npm --prefix web test
cargo fmt --check
cargo test --locked --no-default-features
cargo test --locked --features gui
# Mac 应用与含源码压缩包
bash scripts/package_macos.sh
# Windows PowerShell 安装程序与含源码压缩包
# powershell -File scripts/package_windows.ps1
```

原生 [GUI CI](https://github.com/rayem-prog/CrossDesk/actions/workflows/crossdesk-gui.yml) 同时构建 Mac `.app` 与 Windows NSIS 安装程序，并执行配对、发现策略、界面、剪贴板和 129 MiB 文件测试。自动测试的范围和待做双机验收见 [VALIDATION.md](VALIDATION.md)。交付包包含 `source/`、Rust 依赖源码、Web 依赖许可、提交编号和 SHA-256 校验文件。
