# CrossDesk 0.6.0 文字剪贴板实施记录

已确认范围：双向纯文本，默认开启且独立设置；保持协议 v7，通过能力位协商，与 0.5.0 降级互通。

- 接入图片、文件共用会话及发布队列，保护新的本地复制；远端不回传，同文重新复制可重试。
- LF 规范化；Windows 原生发布 CRLF；保留空白。规范化 UTF-8 上限 1 MiB、分块 16 KiB；空、NUL、非法编码和超限整批跳过。
- TextStart/Chunk/End/Cancel 使用现有加密及 SHA-256；每方向一个批次，30 秒无进展丢弃，不缓存文字正文。
- 原生原子版本校验与发布回执；停用主连接实验文字路径。双方开启才同步，只观察连接后的新复制。
- 持久化 textClipboard 与 CLI --text-clipboard on|off；首页状态及对端能力提示，不记录正文。

实施：测试先行；分离协议/会话、原生适配、设置与 UI 工作；加密回环及原生 CI 回归后提交草稿 PR 和源代码测试包。双机实际粘贴验收后再正式发布，不在本次自动合并或发布。
