# CrossDesk 0.6.1：日常鼠标流畅度

用户已确认：平时移动也卡；同意先优化发送节奏、两端积压和耗时统计。保持协议 v7、配对及剪贴板兼容；独立文件连接留待后续。

Windows 发送线程立即发送空闲后的首个移动；连续移动采用既有 2 ms 默认间隔，使用可被新事件唤醒的 Windows 高精度等待计时器，支持不具备高精度标志时的普通计时器回退。不在钩子中等待网络或计时器，不使用忙等。

两端共用有界事件队列。只合并相邻且每个坐标轴均不反向的 MouseDelta，使用 checked_add，保留最早入队时间和样本数。反向移动、溢出、按键、按钮、滚轮、进入/离开都是边界；禁止跨边界合并。这种保守合并保持边缘逐步裁剪的终点语义。常态无新增接收等待，只压缩已经积压的移动。容量 256 个记录；无法再合并且溢出时终止本会话并释放输入，禁止阻塞钩子、无限排队或静默丢失按钮。

停止时清空队列并唤醒消费者，释放按住的输入；不要在断线后补放旧动作。Mac 使用现有 CGEvent 注入路径。

耗时统计采用固定内存直方图，记录发送排队、网络写入、接收排队、系统注入和发送节奏迟到量。通过环境变量 CROSSDESK_INPUT_METRICS=1 开启，限频输出聚合 p50/p95/p99、最大值、合并数和最大队列深度；不记录键值、坐标、文字、密钥，不将应用注入耗时称为屏幕端到端延迟。
