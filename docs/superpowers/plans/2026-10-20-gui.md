# CrossDesk GUI Implementation Plan

> 2026-10-21 范围已调整：以 [便捷开启传输计划](2026-10-21-easy-start.md) 为当前入口。本文保留设计背景；首页手填 IP/选择 key 文件及“不自动连接”的条款不再适用于本次实施。

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 交付 Mac / Windows 图形界面，让用户通过真实连接状态、配对与同步设置、启动/停止/重连按钮使用 CrossDesk。

**Architecture:** 复用现有 Tauri 2 + React 前端和 ProcessBackend；服务作为独立子进程运行。新增带类型的 stdout 状态事件，保留 stderr 日志与 stdin 停止指令。界面不解析英文日志来推断连接，也不改动 v6 文件传输协议。

**Tech Stack:** Rust 2024、Tauri 2、React/Vite、现有 Noise TCP 核心、tauri-plugin-dialog、Rust 单元/子进程测试、Vitest/Testing Library。

## Global Constraints

- 目标版本 0.4.0；网络协议保持 v6，TCP24920，继续使用已有配对密钥。
- Windows 仍为键鼠服务端，Apple Silicon Mac 仍为客户端；剪贴板双向传输。
- 文件限制保持 512 MiB/文件、2 GiB/批次、64 文件、4 GiB 缓存；图片限制保持现状。
- 不新增网络监听端口，不把服务进程存活显示为已连接。
- GUI 专用通信只使用父子进程管道；结构化状态从 stdout 读取，普通诊断从 stderr 读取。
- GUI 不展示密钥内容；不把密钥放进日志、配置内容、源码或交付包。
- GUI 配置保存在 CrossDesk 的用户配置目录；明确的用户自定义配置路径优先，旧配置只读取迁移，不删除。
- 无参数 GUI 构建打开窗口；无参数无 GUI 构建继续显示帮助；server/client/keygen/--help/--version 命令保留。
- GUI 启动不自动连接；停止、重新连接和退出不能留下旧服务子进程。
- 自动化测试不连接用户的真实设备，不修改日常系统剪贴板。
- GUI 不包含文件夹、断点续传、托盘、自启或传输百分比；这些另写计划。

```rust
#[test]
fn repeated_gui_start_stop_reaps_every_child() {
    for _ in 0..10 {
        let mut command = Command::new(std::env::current_exe().unwrap());
        command.args(["--exact", "control::tests::gui_child_fixture", "--ignored", "--nocapture"])
            .env("CROSSDESK_TEST_CHILD", "1");
        let mut backend = ProcessBackend::default();
        backend.start_command(command).unwrap();
        let deadline = Instant::now() + Duration::from_secs(2);
        loop {
            backend.collect_logs();
            if matches!(backend.connection_state(), ConnectionState::Listening { .. }) { break; }
            assert!(Instant::now() < deadline, "child did not publish structured status");
            thread::sleep(Duration::from_millis(10));
        }
        backend.stop().unwrap();
        assert!(!backend.is_running());
        assert!(backend.child.is_none());
        assert_eq!(backend.connection_state(), &ConnectionState::Stopped);
    }
}
```

基线 Vite 8.0.16 / React 插件 6.0.2 的 engines 为 ^20.19.0 || >=22.12.0，GUI CI 使用满足该约束的 Node 24 主版本，记录实际补丁版本，并用 lockfile 的 npm ci。基础工作流如下；平台脚本负责 bundle 和 package_gui.py，上传路径必须确实存在。

```yaml
name: CrossDesk GUI
on:
  workflow_dispatch:
  pull_request:
    paths: ['src/**', 'web/**', 'scripts/**', 'Cargo.*', 'tauri.conf.json', 'capabilities/**', '.github/workflows/crossdesk-gui.yml']
jobs:
  gui:
    strategy:
      fail-fast: false
      matrix:
        os: [macos-latest, windows-latest]
    runs-on: ${{ matrix.os }}
    steps:
      - uses: actions/checkout@v4
      - uses: actions/setup-node@v4
        with:
          node-version: '24'
      - uses: dtolnay/rust-toolchain@stable
        with:
          components: rustfmt
      - run: npm --prefix web ci
      - run: npm --prefix web test
      - run: npm --prefix web run build
      - run: cargo fmt --check
      - run: cargo test --locked --features gui
      - if: runner.os == 'macOS'
        run: bash scripts/package_macos.sh
      - if: runner.os == 'Windows'
        run: ./scripts/package_windows.ps1
      - uses: actions/upload-artifact@v4
        with:
          name: CrossDesk-GUI-${{ runner.os }}
          path: dist/gui/*.zip
          if-no-files-found: error
```
