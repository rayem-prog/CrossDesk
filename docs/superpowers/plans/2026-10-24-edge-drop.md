# CrossDesk 0.7.0 edge drop implementation plan

**Goal:** Drag local files/folders onto a screen-edge handle, accept and choose a destination on the paired computer, then reveal a complete verified folder without touching the general clipboard.

**Architecture:** A dedicated fresh Noise connection attaches to the live primary session using a one-use ticket. It shares the existing listening port but owns its queues, heartbeat and cancellation. A portable drop engine reuses bounded tree inventory and file codecs; Tauri owns native drop paths and destination selection. Typed local IPC carries commands and snapshots between GUI and child.

**Tech stack:** Rust, existing Noise/SHA-256 file transfer, Tauri 2, React, native Mac/Windows CI.

## Global constraints

- Protocol v7 and existing pairing/preferences remain compatible; capable peers negotiate bit 0x08. Never send new frames to older peers.
- Retain 512 MiB/file, 2 GiB/batch, 64 roots, 10,000 entries, depth 32, 4 MiB manifest, 64 KiB frame and 16 KiB chunk limits.
- No general clipboard access in the drop path. File clipboard synchronization may be disabled independently.
- One incoming and one outgoing job/device, 120-second offer expiry and 30-second stalled-transfer expiry; failed batches never auto-replay.
- Receive in an owned hidden staging directory inside the chosen parent. Verify before an atomic exclusive rename; never overwrite, never delete completed output.
- Main-window close/tray Quit exits; card close rejects/cancels or dismisses. Hidden main polling remains stopped.
- Build and deliver test packages and a draft PR after automation; no formal release, live-app restart or physical acceptance gate.

## Interfaces and ownership

- `edge_drop`: `DropCommand` (Send/Accept/Reject/Cancel/SetEnabled), `DropView`, `DropTransfer`, `command`, `view`, `enabled`, `primary_connected`, `primary_disconnected`, `run_lane`.
- `edge_channel`: bounded authenticated accept/demultiplex, session ticket lifecycle, client auxiliary reconnect. Windows native capture retains its owning session thread.
- `drop_ipc`: bounded command JSON (`crossdesk-drop-command\t`, 4 MiB maximum) and snapshot JSON (`crossdesk-drop\t`, 16 KiB maximum). Control readers consume typed events without copying them into logs.
- GUI commands: get drop state, set left/right/off, accept using a native directory picker, reject, cancel, open verified saved folder, dismiss card. Source paths come only from native drop events.

## Tasks and checks

- [x] Transfer engine: first exercise offers, consent, integrity, cancellation and source mutation with real temporary trees. Split prepared-source sending from clipboard publication, implement same-filesystem exclusive commit and clean owned staging on every failure. Run isolated encrypted round trips in both directions and simultaneously.
- [x] Channel: first test single-use tickets, expired primary sessions, stalled/partial handshakes and an auxiliary failure that leaves primary traffic alive. Implement same-port demultiplexing, independent Noise/cancellation, bounded handshake workers and a registry that shuts down all sockets.
- [x] Local IPC: first prove typed drop events do not become logs, paths containing Chinese/quotes/newlines survive exact round trip, oversize/unknown commands are rejected, and disconnect clears pending state. Add bounded parsing and child-process lifecycle tests.
- [x] Desktop: first test left/right/off persistence, card-close versus main-close policy, native drop routing, recipient selection/cancel, peer compatibility and hidden event handling. Implement edge tab/card windows and minimal capabilities; anchor by primary monitor and DPI.
- [x] Integration: test no content before acceptance, source mutation after offer, collision/Unicode naming, busy state, timeout, reconnect, destination failure and blocked drop traffic with live primary messages. Retain all clipboard/input/reconnect tests using isolated clipboards and fake input sinks.
- [ ] Delivery: bump all owned versions to 0.7.0, build web/native, run package-source checks, commit/push and attach draft PR. Run native Windows and Mac workflows, collect source-inclusive packages, verify executable/signature/installer, source identity and SHA-256, and record exact test limits.

## Presentation defaults

Use the existing warm light surface, quiet system typography and restrained green connection accent. The small edge tab expands into a receiving shelf; all other elements remain simple. Default primary-screen side: Windows right, Mac left. No multi-screen layout editor, transfer history, arbitrary remote-app drops or automatic file execution.
