# CrossDesk 0.5.0 Folder Clipboard Implementation Plan

**Goal:** Finder / Explorer 复制文件夹后，在另一端粘贴完整目录，失败时不发布半成品，不覆盖更新的剪贴板。

**Architecture:** 保留原生顶层路径剪贴板，新增有界、父节点先行的目录清单。扫描只保留路径和元数据，传输时按需打开文件；接收端验证清单后在私有批次目录落地，完成 SHA-256 校验才发布。传输事件通过独立 IPC 汇入首页，不改变连接状态。

**Tech Stack:** Rust、Noise、SHA-256、Tauri / React、NSPasteboard / CF_HDROP。

## Global Constraints

- 基线 816b0ae / 0.4.0；分支 `codex/folder-clipboard`，目标 0.5.0 / 协议 v7。
- 单文件 512 MiB；每批 2 GiB；顶层 64 项；树 10,000 项；深度 32；清单 4 MiB；帧 64 KiB；缓存 4 GiB。
- 支持空目录、多级目录、混选、中文和普通隐藏文件。整批拒绝链接、重解析点、未落地云文件、非法名称、不可读条目。
- 扫描 / 发送可取消；发送前后复核目录及文件。无需重新配对，沿用密钥与偏好。
- 不加入断点续传、后台常驻、传输历史、权限 / 扩展属性 / 链接迁移。
